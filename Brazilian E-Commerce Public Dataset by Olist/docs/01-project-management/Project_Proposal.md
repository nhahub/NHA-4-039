ر# Project Proposal: Olist Brazilian E-Commerce Analysis

## Project Title
Olist E-Commerce Performance Analytics

## Overview
This project analyzes the Brazilian e-commerce platform Olist to uncover insights about customer behavior, seller performance, delivery efficiency, and payment trends. The analysis supports data-driven decision-making for business growth.

## Objectives
- Measure delivery performance and its impact on customer satisfaction.
- Identify top-performing product categories and sellers.
- Segment customers using RFM analysis.
- Forecast monthly sales for 6 months ahead.
- Build an interactive Power BI dashboard.

## Scope
- **Data source**: Olist public dataset (100k+ orders, 2016–2018)
- **Tools**: Python, SQL Server, Power BI, GitHub
- **Deliverables**: Cleaned data, 18 SQL queries, sales forecast, Power BI dashboard, full documentation

## Stakeholders
- CEO – needs overall revenue and growth trends
- Sales Manager – needs top products/categories
- Operations Manager – needs delivery performance
- Marketing Manager – needs customer behavior insights
- Sellers – needs individual performance metrics

## Success Metrics (KPIs)
- Total Revenue: $15.42M
- Average Order Value: $159.83
- On-Time Delivery Rate: > 90%
- Average Review Score: > 4.0 / 5
- Forecast Accuracy: MAE < $350K
