# Olist Brazilian E-Commerce Analysis

## Project Overview
This project analyzes Brazilian e-commerce data from Olist, a marketplace connecting sellers to customers. The analysis covers data cleaning, SQL analysis, sales forecasting, and an interactive Power BI dashboard.

## Key Results

| Metric | Value |
|--------|-------|
| Total Revenue | **$15.42 Million** |
| Total Orders Delivered | **96,000** |
| Average Order Value | **$159.83** |
| Average Delivery Days | **12.09 days** |
| Average Review Score | **4.09 / 5** |
| On-Time Delivery Rate | **92.13%** |

## Tools Used
- **Python** (pandas, numpy, scikit-learn, matplotlib) - Data cleaning & forecasting
- **SQL Server** - Analysis (18 business questions)
- **Power BI** - Interactive dashboard

## Top Insights
- **Best Category:** health_beauty ($2.1M revenue)
- **Best State:** São Paulo (SP) - 45% of revenue
- **Most Used Payment:** Credit Card (78% of orders)
- **Repeat Customer Rate:** 3.12%
- **Forecast Growth:** $69,572 per month
